Sonar is an assistive vision system designed to help visually impaired users understand their surroundings through real-time object detection, proximity awareness and spoken feedback.

The browser prototype runs entirely offline — no servers, no data leaves this tab.

Core capabilities

Real-time awareness

Sonar translates visual information into spoken guidance — helping users navigate spaces, identify objects and read text independently.

01

Object recognition

Recognises common objects such as people, chairs, tables, doors, stairs and vehicles — reporting what it sees in plain language.

02

Proximity awareness

Uses distance information to identify nearby obstacles and provide timely warnings before they become hazards.

03

Spoken feedback

Turns visual information into concise audio guidance — describing the scene, alerting to obstacles and reading text aloud.

04

Text reading

Reads signs, labels and documents aloud using optical character recognition, helping users access printed information.

05

Voice interaction

Lets the user ask for information naturally — "What's in front of me?" or "Read the sign" — using speech recognition.

06

Personal memory

Allows objects and faces to be personalised and remembered, so the system can greet familiar people or locate known items.

System architecture

How Sonar understands the world

Three parallel pipelines work together — turning visual input, spatial data and voice commands into meaningful audio guidance.

Vision pipeline
Camera input Captures the visual scene

Proximity pipeline

Voice pipeline

Speech recognition Parses user intent
Action Executes the request

In practice

What Sonar helps you do

Real situations where spoken environmental awareness makes a meaningful difference.

Walking through a new building

Navigating unfamiliar indoor spaces with confidence — knowing where doorways, stairs and furniture are located.

"Door ahead. Stairs to your right."

Finding an object

Locating personal belongings by asking the system to scan the room and report where common objects are.

"Your backpack is on the chair."

Reading something

Accessing printed information — bus numbers, street signs, product labels, menus — by pointing the camera and asking.

"Bus route 312."

Moving through a busy space

Receiving continuous updates about nearby people and open paths — making crowded environments less overwhelming.

"Three people ahead. Open path on your left."

Architecture

Built with proven, accessible technology

The proposed wearable system uses established open-source components. The browser prototype substitutes equivalent web technologies for the same pipeline.

Hardware (proposed wearable)
Raspberry Pi 4 Central processing unit running all detection and feedback modules
8MP Camera Module Captures the visual scene for object detection and OCR
HC-SR04 Sensor Ultrasonic distance measurement for obstacle detection (20–400 cm)
Bone Conduction Headphones that deliver audio without blocking ambient sounds
Battery Pack 20,000 mAh rechargeable battery for portable operation
Push Buttons Physical controls for mode switching and quick actions
Buzzer Tactile audio alerts for proximity warnings
Software stack
YOLOv8 Real-time object detection model for the wearable; COCO-SSD via TensorFlow.js in the browser prototype
OpenCV Image processing and frame preparation
TensorFlow Lite Optimised inference on edge hardware; TensorFlow.js in the browser
FaceNet Face recognition for personalised identification
Tesseract OCR Optical character recognition for reading text; Tesseract.js in the browser
Whisper Speech-to-text for voice commands; Web Speech API in the browser
gTTS / Festival Text-to-speech for audio feedback; Web Speech API in the browser
SQLite Local database for personalisation; IndexedDB in the browser

Your surroundings should stay yours.

Sonar is designed around local processing, reducing dependence on cloud connectivity and keeping sensitive environmental information close to the device. The camera feed, detection results and personal data are processed on the device itself — nothing is uploaded, nothing is stored externally.

This browser prototype demonstrates the same principle: once the page has loaded, it runs entirely offline. No data leaves this tab.

Looking ahead

Where this could go

The project proposal identifies several directions for extending Sonar's capabilities beyond the initial prototype.

Improved vision models

Adopting newer, more accurate detection architectures as they become available for edge deployment.

Semantic scene understanding

Moving beyond individual object labels to describe spatial relationships and overall scene context.

Depth cameras & LiDAR

Replacing ultrasonic sensors with LiDAR or structured-light depth cameras for richer 3D spatial data.

GPS & IMU integration

Adding location awareness and inertial measurement for outdoor navigation and route guidance.

Thermal & haptic feedback

Thermal sensors for detecting heat sources, and vibration motors for non-audio directional alerts.

Multilingual support

Extending speech synthesis and recognition to additional languages for broader accessibility.

Smart city & emergency integration

Connecting with traffic signals, public transport systems and emergency services for richer contextual awareness.

Companion mobile application

A smartphone app for remote monitoring, configuration, and extending system reach beyond the wearable device.
